# 🌱 个人工作台

一个极简风格的个人效率工具，支持每周自动推送精选文章。

## 功能模块

- 📋 **每日待办清单** - 今日必做/长期计划管理
- 🧠 **认知提升库** - 每周一自动推送优质内容
- 🏙️ **北京生活指南** - 公共资源/出行探店/便民福利
- 💪 **减脂成长站** - 科普知识/激励文案/打卡记录
- 💰 **简易记账本** - 支出记录与统计

## 技术特点

- 纯前端实现，无需后端服务
- GitHub Actions 每周自动抓取新文章
- 本地存储用户数据，隐私安全
- 响应式设计，支持手机访问

## 访问方式

直接打开 GitHub Pages 链接即可使用：
`https://dongshaomeng.github.io/personal-workbench/`

## 自动更新机制

- 每周一北京时间早8点自动运行
- 抓取知乎、小红书、丁香医生等平台内容
- 自动更新 `data/articles.json`
- 页面刷新即可看到新内容

## 手动触发更新

在 GitHub 仓库页面：
1. 点击 "Actions" 标签
2. 选择 "Update Articles Weekly" 工作流
3. 点击 "Run workflow" 按钮
